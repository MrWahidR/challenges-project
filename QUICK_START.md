```powershell

### 3️⃣ ENABLE GITHUB PAGES (2 minutes)
```
1. Go to your GitHub repository
2. Click Settings ⚙️
3. Scroll to "Pages"
4. Branch: main | Folder: / (root)
5. Click Save
6. Wait 1-2 minutes
```

```
