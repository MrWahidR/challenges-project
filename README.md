# 🎯 Challenge Quest - Interactive Brain Teasers & Puzzles

A modern, interactive challenge platform featuring logic puzzles, math problems, word games, and riddles. Built with vanilla HTML, CSS, and JavaScript.

## Features

✨ **Interactive Challenges**
- 12 carefully curated challenges across multiple categories
- Logic puzzles, math problems, word games, and riddles
- Difficulty levels: Easy, Medium, Hard

🎨 **Modern Design**
- Beautiful dark theme with gradient UI
- Smooth animations and transitions
- Fully responsive design for all devices
- Real-time feedback on answers

📊 **Progress Tracking**
- Score counter with points for correct answers
- Challenge completion tracking
- Streak counter
- Category filtering

🚀 **User Experience**
- Instant feedback with explanations
- Ability to skip challenges
- Progress persistence in browser
- Intuitive navigation

## Challenge Categories

- **Logic** - Reasoning and deduction puzzles
- **Math** - Mathematical and probability problems
- **Word** - Anagrams, palindromes, and wordplay
- **Riddles** - Classic and tricky riddles

## Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No installation required!

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/challenges-project.git
   cd challenges-project
   ```

2. **Open in browser**
   - **Option A**: Double-click `index.html`
   - **Option B**: Use a local server
     ```bash
     # Python 3
     python -m http.server 8000
     
     # Python 2
     python -m SimpleHTTPServer 8000
     
     # Node.js (http-server)
     npx http-server
     ```
   - Then open `http://localhost:8000` in your browser

## How to Play

1. **Browse Challenges**
   - View all challenges or filter by category
   - Click any challenge card to start

2. **Solve Challenges**
   - Read the question carefully
   - Select your answer from the options
   - Click "Submit Answer" to check

3. **Learn from Feedback**
   - Get instant feedback on your answer
   - Read explanations to understand the solution
   - Continue to the next challenge

4. **Track Progress**
   - Monitor your score, completed challenges, and streak
   - Complete all categories for maximum points

## Scoring System

- ✓ Correct answer: +10 points
- ✗ Incorrect answer: 0 points + streak reset
- Skip: streak reset, no points
